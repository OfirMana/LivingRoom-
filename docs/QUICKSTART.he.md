# הפעלת LivingRoom

## הפעלה בלי Visual Studio

1. היכנסו ל־[בדיקות הבנייה](https://github.com/OfirMana/LivingRoom-/actions/workflows/build.yml)
   ובחרו הרצה מוצלחת של `Windows build`.
2. בתחתית ההרצה, תחת Artifacts, הורידו את `LivingRoom-Windows-x64`.
3. חלצו את ההורדה. בתוכה יש ZIP של האפליקציה וקובץ SHA-256; חלצו גם את ה־ZIP הפנימי.
4. בתוך התיקייה המחולצת, לחצו פעמיים על `Start-LivingRoom.cmd`.
5. השאירו את חלון השרת פתוח לצד האפליקציה.

בהפעלה הראשונה יש ליצור משפחה חדשה ומשתמש. סמנו את המשתמש הראשון כמנהל.
אין בחבילת ההדגמה משתמשים או סיסמאות מהפרויקט המקורי.

## דרישות

- Windows של 64 ביט.
- ‎.NET Framework 4.7.2 ומעלה ממשפחת 4.x.
- מנוע Access מסוג ACE 16.0 בגרסת 64 ביט.
- WebView2 עבור תצוגת היומן.

אם חסר מנוע Access, שמרו את הודעת השגיאה ובדקו את דרישות ההתקנה לפני שינוי
התקנת Office קיימת. אין צורך להתקין Visual Studio כדי להריץ את החבילה.

## מה נשמר והיכן

המשפחות והנתונים החדשים נשמרים בקובץ `.local/LivingRoom.accdb` בתיקיית האפליקציה.
גבו קובץ זה כשהשרת סגור. עדכון חבילת האפליקציה צריך לשמור את תיקיית `.local`.
אין להעלות אותה ל־GitHub.

יומן Google הוא רכיב אופציונלי שדורש הגדרה נפרדת. ללא הגדרה תופיע הודעה ברורה.
בדיקות השירות עברו, אך כל מסכי האפליקציה ויומן Google עדיין דורשים בדיקה חזותית.

## סיום

סגרו את האפליקציה ואת חלון השרת. אין צורך להשאיר שרת פעיל ברקע.
